Detection System Redesign

A simple, white-background system view of Campaigns, Kits, and Workflows.

Main Idea

Separate scam intelligence into three parts so investigators can clearly explain what happened, how it was found, and which tooling was involved.

Part Meaning
CampaignA specific scam wave happening now.
KitReusable attacker toolkit/template.
WorkflowDetection rule or search automation.

Campaign

Case file for a scam operation: targets, dates, evidence, URLs, templates, and favicon variants.

Kit

Reusable attack engine (e.g., Tycoon 2FA, FEMITBOT) used across many brands.

Workflow

Automation that hunts suspicious URLs and can be scoped to campaign, kit, brand, or exploration.
